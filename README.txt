LinuxのマニュアルページをAIで日本語に翻訳するリポジトリ。翻訳には以下のプロンプトを使用している。

[ファイル名]は英語のmanページのroffソースです。日本語版manページを作成してください。

roffの構造・マクロ・エスケープシーケンス・制御用の引数は変更せず、ユーザーに表示される英語の文章だけを自然な日本語に翻訳してください。
特に以下を守ってください。
- .SH や .SS などのroff命令自体は変更しない。見出しとして表示される引数は翻訳してよい。
- .IX Header、.IX Item などの制御用引数（Header、Item 等）は翻訳しない。ただし、その後にある表示内容・索引内容は必要に応じて翻訳する。
- \fB、\fI、\fR、\&、\-、\[... ] などのroffエスケープを壊さない。
- コマンド名、オプション名、ファイル名、環境変数、コード、SYNOPSISの構文など、翻訳すべきでない技術的な文字列は原文のまま維持する。
- 原文の意味を省略・要約・追加せず、manページとして自然で正確な日本語にする。
- 日本語の句読点の後などに、英語原文由来の不要な半角スペースを残さない。
- 日本語組版のため、ファイルの冒頭に .mso ja.tmac と .ad 1 を追加する。
- 完成したroffファイルをそのまま保存できる形で出力する。

作業は以下の手順で進めてください。
1. 原文を日本語に翻訳する。
2. roffを壊していないか原文と比較して検査する。
3. 問題があれば修正する。
